# Portafolio — Rebeca Medina Gómez

Portafolio personal construido con React + Vite, tema oscuro con tonalidades moradas.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

Esto genera la carpeta `dist/`, lista para desplegar en Netlify, Vercel o cualquier hosting estático (arrastra la carpeta `dist` a Netlify, igual que con tus otros proyectos).

## Personalizar contenido

Todo el texto (perfil, proyectos, experiencia, skills) vive en `src/data.js` — edita ahí sin tocar los componentes.
